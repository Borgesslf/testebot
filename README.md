# 📋 TpJotoba
[Descrição detalhada baseada no enunciado]
Este projeto é um sistema para a gestão de uma frota de transporte, incluindo a administração de carros para gerentes e caminhões para cargas. O sistema é projetado para calcular os custos de pedágios e manutenção, enquanto garante a segurança contra dados inválidos.

👨‍💻 Desenvolvido por Luis Felipe de Oliveira Borges na Universidade Santa Cecília (Unisanta).

⚙️ Funcionalidades:
- Cadastro de veículos (Carro e Caminhão)
- Simulação de viagens com cálculo de consumo de combustível e custos de pedágio
- Tratamento de exceções para dados inválidos
- Utilização de herança e polimorfismo na implementação do sistema

🧠 Tecnologias:
- Linguagem: C#
- IDE: Visual Studio

▶️ Como Executar:
1. Abra o projeto no Visual Studio.
2. Compile o projeto.
3. Execute o arquivo 'Program.cs'.
4. Siga as instruções exibidas no console para cadastrar veículos e simular a viagem.
